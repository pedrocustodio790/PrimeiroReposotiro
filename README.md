## Meu primeiro repositorio Com o Senac 
 O primeiro proejto enviado no senac para o github 

## como enviar projetos para o github

- precisa ter o **GIT** instalaod e o **Github desktop**
- abrir o **cmd** na pasta do projeto e dar `git init` no prompt de comando 
- fazer o **commit** no githuib desktop e depois clicar em `push` para enviar
    - se é a primeira vez, precisa clicar em `publish`
    - lembrar de preferncialmente deixar o projeto **public**
## Como baixar projetos
- abrir o **cmd** e digitiar `git clone url do projeto`
